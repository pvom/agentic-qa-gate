What the gate does

  • Behaviour — Playwright e2e across viewports + unit tests + typecheck.
  • Visual regression — screenshots across 8 viewports × pages vs a baseline, mobile-first.
  • DS static audit — scans source for hardcoded colours / arbitrary spacing / a11y.
  • DS runtime color audit — the standout: computed colour vs authorized palette, in a real browser.

The AI agent runs all of this and returns an evidence-based APPROVE / REJECT verdict. See a sample verdict report and the full source on GitHub.
